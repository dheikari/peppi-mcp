# README logo generation

The Peppi MCP wordmark was made with the built-in imagegen tool for the README header. The layout takes inspiration from [Torium's README](https://github.com/ahnl/torium); the lettering, book motif and blue/teal artwork were generated for this project.

## Initial prompt

Use case: logo-brand. Asset type: GitHub README header logo for Peppi MCP. Create one original, polished, playful sticker-style wordmark on a truly transparent background. Exact text: "Peppi MCP". Make "Peppi" the large readable centerpiece in rounded friendly bold lettering, and "MCP" a small clean secondary label below it. Integrate a subtle open-book or study-page motif into one letter, with two tiny connected dots as a restrained reference to connecting tools. Use a crisp cool blue and teal identity, substantial white sticker edging so it reads on both light and dark backgrounds, flat vector-like shapes, smooth curves, and minimal detail. A wide compact logo, tightly framed with modest transparent margins, readable when displayed at 360 pixels wide. No Japanese text, no extra slogan, no background rectangle, no mockup, no watermark, no university crest, no existing Peppi or Torium branding. The aesthetic is a friendly open-source project wordmark, with its own distinctive design.

## Refinement prompt

Refine this Peppi MCP logo for the finished GitHub README. Change only the outer cutout and outline quality: replace the rough, speckled, distressed fringe with a perfectly clean smooth continuous white sticker border and fully transparent space outside it. Remove all stray white pixels and flecks around the silhouette. Preserve the exact Peppi MCP lettering, composition, blue/teal colors, book in the P, connected-dot detail, and readable wordmark. No new text or objects, no background rectangle. The final alpha edges must look like a clean vector sticker, not torn paper.
